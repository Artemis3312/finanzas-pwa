1.1 Topología Offline-First & Sincronización LWW

La PWA implementa el patrón Local-First / Offline-First. La interfaz de usuario lee y escribe exclusivamente en IndexedDB (vía Dexie.js) con latencia cero. Cada mutación genera un identificador único universal (UUID v4), asigna la marca de tiempo exacta en milisegundos UTC (updated_at) y marca el registro con sync_status = 'pending'.

  • 1 Moneda Pivote (USD): Todas las tasas de cambio se almacenan como unidades de divisa por cada 1.00 USD. Al registrar una transacción, se congela de forma inmutable exchange_rate_used y amount_usd_pivot = original_amount / exchange_rate_used.
  • 2 Resolución de Conflictos (Last-Write-Wins): Durante el ciclo PUSH/PULL hacia Google Sheets, el motor compara incoming.updated_at > existing.updated_at. El registro con mayor marca temporal prevalece.
  • 3 Borrado Lógico (Soft Delete): Ningún registro se destruye físicamente al ser eliminado por el usuario; se actualiza is_deleted = 1 y updated_at = Date.now() para propagar la baja a todos los dispositivos conectados.

1.2 Inmutabilidad Histórica vs. Conversión Dinámica

A. En el momento del registro (Inmutable):

Si el usuario registra un gasto de 4,550.00 BS cuando la tasa manual es 45.50 BS/USD:

original_amount: 4550.00
original_currency: "BS"
exchange_rate_used: 45.50 // Inmutable
amount_usd_pivot: 100.00 // Inmutable (4550 / 45.50)

B. Al visualizar saldos de cuentas (Dinámico):

El saldo nativo de cada cuenta es la suma algebraica exacta en su moneda original. Al alternar el selector superior a cualquier moneda destino M_dest:

saldo_USD = saldo_nativo / tasa_actual[moneda_cuenta]
saldo_M_dest = saldo_USD * tasa_actual[M_dest]

Code.gs — Endpoints Bidireccionales GET/POST & Resolución de Conflictos

/**
 * ============================================================================
 * FINANZAS PWA - BACKEND SINCRONIZACIÓN BIDIRECCIONAL (Code.gs)
 * ============================================================================
 * Soporta:
 * - Inicialización automática de hojas y cabeceras (accounts, transactions, debts, exchange_rates)
 * - Bloqueo de concurrencia mediante LockService
 * - Resolución de conflictos Last-Write-Wins (updated_at en milisegundos UTC)
 * - Borrado lógico (is_deleted = 1)
 * - Peticiones POST con Content-Type: text/plain;charset=utf-8 para evitar bloqueos CORS preflight
 */

const TABLES = {
  accounts: [
    'id', 'name', 'currency', 'initial_balance', 'color', 'icon',
    'created_at', 'updated_at', 'is_deleted'
  ],
  transactions: [
    'id', 'account_id', 'debt_id', 'type', 'category', 'description',
    'original_amount', 'original_currency', 'exchange_rate_used', 'amount_usd_pivot',
    'tx_date', 'created_at', 'updated_at', 'is_deleted'
  ],
  debts: [
    'id', 'kind', 'counterparty', 'title', 'currency', 'total_amount',
    'paid_amount', 'exchange_rate_created', 'due_date', 'status',
    'created_at', 'updated_at', 'is_deleted'
  ],
  exchange_rates: [
    'id', 'currency', 'rate_to_usd', 'symbol', 'updated_at', 'is_deleted'
  ]
};

/**
 * Endpoint GET: Permite verificar el estado del servicio o descargar deltas (?since=timestamp)
 */
function doGet(e) {
  try {
    ensureSheetsExist_();
    const since = e && e.parameter && e.parameter.since ? Number(e.parameter.since) : 0;
    const serverData = pullChangesSince_(since);

    return buildJsonResponse_({
      status: 'ok',
      server_timestamp: Date.now(),
      changes: serverData
    });
  } catch (err) {
    return buildJsonResponse_({ status: 'error', message: err.toString() });
  }
}

/**
 * Endpoint POST: Sincronización bidireccional en una sola transacción atómica.
 * Recibe los cambios locales pendientes (push) y devuelve las novedades del servidor (pull).
 */
function doPost(e) {
  const lock = LockService.getScriptLock();
  lock.waitLock(25000); // Evita condiciones de carrera entre múltiples dispositivos

  try {
    ensureSheetsExist_();
    const rawBody = e && e.postData && e.postData.contents ? e.postData.contents : '{}';
    const payload = JSON.parse(rawBody);

    const lastSyncAt = Number(payload.last_sync_at || 0);
    const clientChanges = payload.changes || {};
    const stats = { inserted: 0, updated: 0, ignored_older: 0 };

    // 1. APLICAR PUSH DEL CLIENTE CON RESOLUCIÓN DE CONFLICTOS (updated_at)
    Object.keys(TABLES).forEach(tableName => {
      const incomingRows = clientChanges[tableName] || [];
      if (incomingRows.length > 0) {
        const tableStats = upsertTableRows_(tableName, TABLES[tableName], incomingRows);
        stats.inserted += tableStats.inserted;
        stats.updated += tableStats.updated;
        stats.ignored_older += tableStats.ignored_older;
      }
    });

    // 2. EXTRAER PULL DEL SERVIDOR (Registros con updated_at > lastSyncAt)
    const serverChanges = pullChangesSince_(lastSyncAt);

    return buildJsonResponse_({
      status: 'ok',
      server_timestamp: Date.now(),
      stats: stats,
      changes: serverChanges
    });
  } catch (err) {
    return buildJsonResponse_({ status: 'error', message: err.toString() });
  } finally {
    lock.releaseLock();
  }
}

/**
 * Inserta o actualiza registros comparando marcas de tiempo (updated_at)
 */
function upsertTableRows_(sheetName, headers, incomingRecords) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(sheetName);
  const data = sheet.getDataRange().getValues();

  const idIdx = headers.indexOf('id');
  const updatedIdx = headers.indexOf('updated_at');

  // Mapa rápido de UUID -> índice de fila en la hoja (1-based)
  const existingMap = {};
  for (let r = 1; r < data.length; r++) {
    const rowId = String(data[r][idIdx]);
    if (rowId) {
      existingMap[rowId] = {
        rowNumber: r + 1,
        updatedAt: Number(data[r][updatedIdx] || 0)
      };
    }
  }

  let inserted = 0, updated = 0, ignored_older = 0;

  incomingRecords.forEach(record => {
    const recId = String(record.id);
    const recUpdatedAt = Number(record.updated_at || Date.now());
    const rowArray = headers.map(col => (record[col] !== undefined && record[col] !== null) ? record[col] : '');

    if (!existingMap[recId]) {
      sheet.appendRow(rowArray);
      inserted++;
    } else {
      const currentServerUpdated = existingMap[recId].updatedAt;
      // Regla Last-Write-Wins: Solo sobrescribe si el registro entrante es más reciente o igual
      if (recUpdatedAt >= currentServerUpdated) {
        sheet.getRange(existingMap[recId].rowNumber, 1, 1, headers.length).setValues([rowArray]);
        updated++;
      } else {
        ignored_older++;
      }
    }
  });

  return { inserted, updated, ignored_older };
}

/**
 * Obtiene todos los registros modificados después de `sinceTimestamp`
 */
function pullChangesSince_(sinceTimestamp) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const result = {};

  Object.keys(TABLES).forEach(tableName => {
    const headers = TABLES[tableName];
    const sheet = ss.getSheetByName(tableName);
    const rows = sheet.getDataRange().getValues();
    const updatedIdx = headers.indexOf('updated_at');
    const list = [];

    for (let r = 1; r < rows.length; r++) {
      const rowUpdated = Number(rows[r][updatedIdx] || 0);
      if (rowUpdated >= sinceTimestamp) {
        const obj = {};
        headers.forEach((h, i) => {
          obj[h] = rows[r][i];
        });
        list.push(obj);
      }
    }
    result[tableName] = list;
  });

  return result;
}

/**
 * Crea automáticamente las pestañas y encabezados si el Google Sheet está vacío
 */
function ensureSheetsExist_() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  Object.keys(TABLES).forEach(tableName => {
    let sheet = ss.getSheetByName(tableName);
    if (!sheet) {
      sheet = ss.insertSheet(tableName);
      sheet.appendRow(TABLES[tableName]);
      sheet.getRange(1, 1, 1, TABLES[tableName].length).setFontWeight('bold');
      sheet.setFrozenRows(1);
    }
  });
}

function buildJsonResponse_(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

Cleaner.gs — Purga Automática de Historial (> 2 Años)

/**
 * ============================================================================
 * FINANZAS PWA - CRON JOB DE RETENCIÓN DE DATOS DE 2 AÑOS (Cleaner.gs)
 * ============================================================================
 * Elimina físicamente de Google Sheets:
 * 1. Transacciones cuya fecha (tx_date o created_at) supere los 2 años (730 días).
 * 2. Deudas pagadas o marcadas con borrado lógico (is_deleted = 1) con más de 2 años.
 */

const TWO_YEARS_MS = 2 * 365 * 24 * 60 * 60 * 1000; // 63,072,000,000 ms

/**
 * Función principal ejecutada por el Trigger Temporal diario
 */
function purgeOldHistoricalData() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const cutoffTimestamp = Date.now() - TWO_YEARS_MS;

  // 1. Purgar Transacciones mayores a 2 años
  const txSheet = ss.getSheetByName('transactions');
  if (txSheet) {
    const rows = txSheet.getDataRange().getValues();
    const headers = rows[0] || [];
    const txDateIdx = headers.indexOf('tx_date');
    const createdIdx = headers.indexOf('created_at');

    // Iteración inversa (bottom-up) para no alterar los índices al eliminar filas
    for (let r = rows.length - 1; r >= 1; r--) {
      const rawTxDate = rows[r][txDateIdx];
      const createdAt = Number(rows[r][createdIdx] || 0);
      const effectiveTime = rawTxDate ? new Date(rawTxDate).getTime() : createdAt;

      if (effectiveTime > 0 && effectiveTime < cutoffTimestamp) {
        txSheet.deleteRow(r + 1);
      }
    }
  }

  // 2. Purgar Deudas saldadas o eliminadas mayores a 2 años
  const debtSheet = ss.getSheetByName('debts');
  if (debtSheet) {
    const rows = debtSheet.getDataRange().getValues();
    const headers = rows[0] || [];
    const updatedIdx = headers.indexOf('updated_at');
    const statusIdx = headers.indexOf('status');
    const deletedIdx = headers.indexOf('is_deleted');

    for (let r = rows.length - 1; r >= 1; r--) {
      const updatedAt = Number(rows[r][updatedIdx] || 0);
      const status = String(rows[r][statusIdx]);
      const isDeleted = Number(rows[r][deletedIdx] || 0) === 1;

      if ((status === 'PAID' || isDeleted) && updatedAt > 0 && updatedAt < cutoffTimestamp) {
        debtSheet.deleteRow(r + 1);
      }
    }
  }
}

/**
 * Ejecuta esta función UNA SOLA VEZ desde el editor de Google Apps Script
 * para dejar programado el Cron Job automático todos los días a las 03:00 AM.
 */
function installTwoYearRetentionTrigger() {
  const existingTriggers = ScriptApp.getProjectTriggers();
  existingTriggers.forEach(t => {
    if (t.getHandlerFunction() === 'purgeOldHistoricalData') {
      ScriptApp.deleteTrigger(t);
    }
  });

  ScriptApp.newTrigger('purgeOldHistoricalData')
    .timeBased()
    .everyDays(1)
    .atHour(3)
    .create();
}

sw.js (Service Worker)

const CACHE_NAME = 'finanzas-pwa-v1.2';
const APP_SHELL = [
  './',
  './index.html',
  './manifest.json',
  'https://cdn.tailwindcss.com',
  'https://unpkg.com/dexie@3.2.4/dist/dexie.min.js',
  'https://unpkg.com/lucide@latest'
];

self.addEventListener('install', event => {
  event.waitUntil(
    caches.open(CACHE_NAME).then(cache => cache.addAll(APP_SHELL))
  );
  self.skipWaiting();
});

self.addEventListener('activate', event => {
  event.waitUntil(
    caches.keys().then(keys =>
      Promise.all(keys.filter(k => k !== CACHE_NAME).map(k => caches.delete(k)))
    )
  );
  self.clients.claim();
});

self.addEventListener('fetch', event => {
  const url = new URL(event.request.url);

  // Nunca interceptar llamadas de sincronización a Google Apps Script
  if (url.hostname.includes('script.google.com') || url.hostname.includes('googleusercontent.com')) {
    return;
  }

  // Estrategia Stale-While-Revalidate para activos estáticos y navegación
  event.respondWith(
    caches.match(event.request).then(cachedResponse => {
      const fetchPromise = fetch(event.request)
        .then(networkResponse => {
          if (networkResponse && networkResponse.status === 200 && event.request.method === 'GET') {
            const clone = networkResponse.clone();
            caches.open(CACHE_NAME).then(cache => cache.put(event.request, clone));
          }
          return networkResponse;
        })
        .catch(() => cachedResponse);

      return cachedResponse || fetchPromise;
    })
  );
});

Guía Paso a Paso: Despliegue en GitHub Pages y Conexión con Google Sheets

FASE 1: Configurar Google Sheets & Apps Script
  1. Crea una hoja de cálculo nueva en Google Sheets (ej. FinanzasPWA_DB).
  2. En el menú superior, abre Extensiones > Apps Script.
  3. Reemplaza el contenido de Código.gs con el bloque Code.gs de la pestaña anterior.
  4. Haz clic en el icono (+) > Secuencia de comandos, nómbralo Cleaner y pega el código de Cleaner.gs.
  5. Selecciona la función installTwoYearRetentionTrigger en la barra superior y pulsa Ejecutar (acepta los permisos de tu cuenta Google). Esto activará la purga automática de registros mayores a 2 años.
  6. Haz clic en Implementar > Nueva implementación.
  7. Elige tipo: Aplicación web. En Ejecutar como selecciona Yo, y en Quién tiene acceso selecciona Cualquier persona (necesario para peticiones CORS desde GitHub Pages).
  8. Copia la URL de la aplicación web generada (termina en /exec).
FASE 2: Publicar en GitHub Pages y Vincular
  1. Crea un nuevo repositorio en GitHub (ej. finanzas-pwa).
  2. Sube este archivo index.html junto con los archivos manifest.json y sw.js en la raíz del repositorio.
  3. En tu repositorio de GitHub, entra en Settings > Pages.
  4. En Build and deployment > Branch, selecciona main y carpeta / (root), luego pulsa Save.
  5. Abre la URL HTTPS generada (https://tu-usuario.github.io/finanzas-pwa/) desde el navegador de tu teléfono móvil.
  6. Pulsa el icono de Sincronización (arriba a la derecha) en la PWA, pega la URL https://script.google.com/macros/s/.../exec y pulsa Sincronizar Ahora.
  7. En tu móvil (Chrome en Android o Safari en iOS), selecciona "Añadir a pantalla de inicio" para instalarla como aplicación nativa independiente.
